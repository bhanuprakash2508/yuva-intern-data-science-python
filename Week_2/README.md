## Dataset
UCI Adult / Census Income Dataset — UCI Dataset ID 2.

## Objective
Perform exploratory data analysis, summarize basic statistics, identify patterns and anomalies, create annotated visualizations, and interpret the findings.

## Run
```bash
pip install -r requirements.txt
python week2_eda.py
```

The script creates an `outputs/` folder containing:
- numerical and categorical summaries
- income distribution
- age and working-hours distributions
- education distribution
- education vs income analysis
- age vs income analysis
- hours vs income analysis
- numerical correlation matrix
- additional categorical counts
- automated key-findings text

## Reproducibility
The script downloads the same public UCI Adult dataset used in Week 1. Runtime numbers and visualizations should be generated by executing the script; do not fabricate screenshots or numerical results.
