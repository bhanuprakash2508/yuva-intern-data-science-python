This Week 1 submission documents a complete data acquisition, cleaning, and preprocessing workflow using the UCI Adult (Census Income) dataset. The dataset was selected because it contains mixed numerical and categorical variables and documented missing values, making it suitable for demonstrating practical data-preparation techniques. The workflow begins with reproducible acquisition from the UCI Machine Learning Repository and initial inspection of dimensions, columns, data types, and missing-value markers. Source values represented by “?” are converted into explicit missing values before further analysis.

The cleaning stage standardizes column names, trims categorical text, normalizes the income target labels, and treats missing categorical values transparently. Duplicate records are quantified rather than automatically removed, because identical rows may represent different observations. Numerical variables are checked against clear domain constraints, while statistical outliers are investigated using the IQR method and boxplots. The report distinguishes unusual observations from logically invalid data and avoids indiscriminate deletion.

For downstream machine learning, the target is separated from the predictors and the data is split into training and testing sets before fitting preprocessing transformations. Numerical features use median imputation and standard scaling, while categorical features use imputation and one-hot encoding. A Scikit-learn ColumnTransformer and Pipeline are used to reduce preprocessing inconsistency and prevent data leakage. The project also documents the potential effects and limitations of preprocessing choices. The accompanying Python script is reproducible and generates the cleaning reports, visualizations, processed dataset, and preprocessing outputs required for further analysis.
