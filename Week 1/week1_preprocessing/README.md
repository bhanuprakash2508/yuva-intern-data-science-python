## Objective
Acquire a public dataset, inspect its structure and quality, handle missing values and inconsistent entries, investigate duplicates and outliers, and build a leakage-safe preprocessing pipeline for later analysis or machine learning.

## Tools
Python, Pandas, NumPy, Matplotlib, Scikit-learn, ucimlrepo.

## Run
```bash
pip install -r requirements.txt
python week1_preprocessing.py
```

The script downloads the dataset from UCI and creates an `outputs/` folder containing:
- first five rows
- missing-value reports
- duplicate report
- range checks
- IQR outlier report
- boxplots
- cleaned dataset
- preprocessing output
