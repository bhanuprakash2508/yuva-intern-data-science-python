# YuvaIntern Week 6 — Integrative Capstone Project

## Project
End-to-end data science analysis of the UCI Adult / Census Income dataset.

## Pipeline
1. Public data acquisition
2. Data cleaning
3. Feature engineering
4. Exploratory Data Analysis
5. K-Means unsupervised clustering
6. Logistic Regression supervised classification
7. TensorFlow/Keras dense neural-network comparison
8. Cross-validation and test evaluation
9. Visualization
10. Model comparison and insights

## Run
```bash
pip install -r requirements.txt
python week6_capstone.py
```

Runtime outputs are saved in `outputs/`.

- `eda_summary.txt`
